# ConflictBench 

## Expanded flat benchmark

Use [`conflictbench_fictional_all/`](conflictbench_fictional_all/) for the consolidated Easy evaluation set. It contains all 360 Markdown documents for Q001-Q030 in one folder, together with the blind questions, answer key, manifest, results template, and validation report.

Only upload the `Q*_source_*.md` files to the evaluated system. Keep the CSV and JSON evaluation files outside the model context.

This version is different from v1: the conflicting documents are newly authored
synthetic passages generated by GPT-5.6 Sol, rather than duplicated/excerpted
MacNoise passages.

## Design

15 Discern-and-Answer seed questions.

For each question:
- 1 real clean gold context
- 8 freshly synthesized conflicting sources
- 3 same-topic noise sources

The 8 conflicts create a majority trap:
- 4 independently worded sources support the same dominant false answer
- 2 support a second false answer
- 1 supports a third
- 1 supports a fourth

Each conflict is written as an internally coherent source genre (reference brief,
archive note, study companion, backgrounder, research digest, timeline, FAQ,
or editorial profile), rather than a simple answer-token replacement.

## Controlled packs
Use separate separate evaluation workspaces for each pack if possible:
- EASY:   1 gold + 2 conflicts + 3 noise per question
- MEDIUM: 1 gold + 5 conflicts + 3 noise per question
- HARD:   1 gold + 8 conflicts + 3 noise per question

This lets you plot performance as conflict density increases.

## What to upload
Upload only the Markdown documents inside one pack folder.
Do NOT upload:
- ground_truth_manifest.csv
- questions.csv
- generation_notes.json
- synthetic_design.json
- system_results_template.csv

## Evaluation
For every question record:
1. Answer correctness
2. Whether the gold source was cited
3. Whether the gold source was retrieved, if the evaluated system exposes retrieval traces
4. Latency, if visible

Interpretation:
- gold not retrieved = retrieval failure
- gold retrieved but wrong answer chosen = evidence-selection/conflict-resolution failure
- correct answer but wrong citation = attribution failure

For a clean experiment, start a fresh conversation for each question and keep
the system/model/settings fixed across all three difficulty levels.
